Para salvar seus dados na nuvem e acessar de qualquer dispositivo, conecte ao Supabase. Siga os passos abaixo — leva menos de 10 minutos.

1
Acesse supabase.com e crie uma conta gratuita (pode entrar com o GitHub).
2
Clique em New Project, dê um nome (ex: financas), escolha uma senha e selecione a região South America (São Paulo). Aguarde ~2 minutos.
3
No menu lateral, vá em SQL Editor, cole o script abaixo e clique em Run para criar as tabelas.
Ver script SQL ▾ 
create table gastos (
  id bigint generated always as identity primary key,
  mes text not null,
  data date not null,
  descricao text not null,
  valor numeric not null,
  categoria text not null,
  cartao text not null,
  obs text,
  created_at timestamptz default now()
);

create table parcelas (
  id bigint generated always as identity primary key,
  descricao text not null,
  total numeric not null,
  num_parcelas int not null,
  parcela_atual int not null,
  inicio text not null,
  cartao text not null,
  categoria text not null,
  valor_parcela numeric not null,
  created_at timestamptz default now()
);

create table ativos (
  id bigint generated always as identity primary key,
  tipo text not null,
  ticker text not null,
  banco text not null,
  cotas numeric,
  preco_medio numeric,
  valor_fixo numeric,
  cotacao numeric,
  variacao numeric default 0,
  notas text,
  updated_at timestamptz,
  created_at timestamptz default now()
);

alter table gastos enable row level security;
alter table parcelas enable row level security;
alter table ativos enable row level security;

create policy "public_all" on gastos for all using (true) with check (true);
create policy "public_all" on parcelas for all using (true) with check (true);
create policy "public_all" on ativos for all using (true) with check (true);
4
Vá em Project Settings → API, copie a Project URL e a chave anon public e cole abaixo.
